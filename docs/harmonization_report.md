## Summary

Three chronic-disease surveillance domains (diabetes, vision and eye health,
kidney disease) are published on data.cdc.gov by four systems with **four
different table layouts**. Each one encodes the same ideas differently:
indicator, measure type, stratifier, confidence interval and suppression flag.
This project maps all four onto one long-format indicator model using seed
tables (crosswalks, catalogs, FIPS geography), and tests the result with dbt.

The analogy is a **universal power adapter**. Each source system has its own
plug shape (columns, codes, conventions). The crosswalks are the adapters. The
harmonized fact table is the single socket that a dashboard, report or new
analysis can plug into. The adapters live in reviewed CSV files, not inside code.

## What harmonization required

| Difference | Example from the data | How the model handles it |
|---|---|---|
| Measure type stored in different places | USDSS puts "Crude" / "Age-Adjusted" in the **age** column next to real age bands; the others use a `data_value_type` column | Split in the intermediate model into a `source_measure` label, then crosswalked to `measure_type` |
| Stratifier layout | USDSS: one column per stratifier. VEHSS: cross-classified cells (28,450 rows have more than one stratifier). BRFSS: one break-out pair. CDI: up to three pairs | Reshaped to one `strat_category`/`strat_value` per row; cross-classified cells excluded and counted |
| Vocabulary for the same group | "Male" / "Male"; "65+" / "65 years and older" / "Age >=65" | `seed_stratification_crosswalk` maps to `sex:male`, `age_group:65+` |
| Non-equivalent groups | Age bands 18–44 vs 18–39; VEHSS "Asian" (ethnicity unspecified) vs "Asian, non-Hispanic" | Kept as separate harmonized values, with age bounds and comparability notes in `dim_stratification` |
| Question ids change over time | BRFSS kidney: CHCKIDNY → CHCKDNY1 → CHCKDNY2 | Three crosswalk rows to one `CKD_SELF_REPORT` |
| Suppression conventions | Text "Suppressed" (USDSS), `#` (VEHSS), `*`/`**`/`***` (BRFSS), `*`/`****` (CDI) | Normalized to `data_status` and `suppressed_flag`; footnote text retained |
| Impossible published values | 18.0 VEHSS lower CIs below 0% | Floored to 0 with `ci_low_floored_flag`; published value kept in `ci_low_published` |
| Numeric precision | VEHSS publishes 2 decimals, others 1; 531 BRFSS values carry floating-point artifacts (e.g. `5.779999999999999`) | Stored as double; noted for display rounding |
| Non-estimate rows | BRFSS "median of states" rows (56 rows); CDI ESKD counts (208 rows) | Excluded by design (`include=false` in the crosswalk for counts) |
| Method breaks | USDSS labels BRFSS ≤2010 and ≥2011 separately | Both map to `data_source = BRFSS`; the break is kept in `method_note` |

## Findings

### 1. Overlapping sources agree closely, with one exception

| Pair | Matched cells (both reported) | Mean abs. difference | Within 0.5 pp | CIs overlap |
|---|---|---|---|---|
| Diagnosed diabetes, CDI vs USDSS (crude) | 1,948 | 0.2 pp | 88.8% | 99.7% |
| Vision difficulty, BRFSS Prevalence vs VEHSS (crude) | 3,158 | 0.05 pp | 99.5% | 100.0% |

The diabetes disagreement is concentrated in **2020**: 36.2% of
matched cells differ by more than 0.5 pp (mean absolute difference
0.68 pp), compared with 2.7–4.0% in
other years. **The cause is not determined from these data**; neither dataset
documents why its 2020 values differ from the other's. As possible context only,
CDC's *Comparability of Data, BRFSS 2020* documents that 2020 data collection was
disrupted (collection "was interrupted in some areas for a short time", many
states did not collect all 12 monthly samples, and 32 states, DC and Puerto Rico
continued collection into early 2021).[^brfss2020] That document describes the
survey, not how USDSS or CDI processed 2020 data, so it does not explain the
difference between them. The practical lesson for harmonization is descriptive:
two systems that look interchangeable can still diverge for a single year.
That is why the model keeps both and marks a primary source instead of averaging
them.

[^brfss2020]: Centers for Disease Control and Prevention. *Behavioral Risk Factor Surveillance System: Comparability of Data, BRFSS 2020.* August 2021, section A. <https://www.cdc.gov/brfss/annual_data/2020/pdf/compare-2020-508.pdf>

The two sources also disagree on suppression for 20 crude
diabetes cells and 122 vision cells: one system marks the
cell suppressed and the other does not (it publishes a value or marks it not
available). The same underlying survey can show a value in one system and hide
it in another.

### 2. Coverage gaps are larger than schema gaps

* **Years:** USDSS diabetes covers 2000–2024. VEHSS vision ends in 2022. CDI ESKD
  covers 2019–2022. The latest year shared by all pilot indicators is
  **2022**.
* **Measures:** self-reported kidney disease is published **crude only**, so
  cross-domain state comparisons have to use crude prevalence.
* **Stratifiers:** only sex and the 65+ age group are close to universal. Income
  appears only in BRFSS Prevalence; diabetes/hypertension/smoking status only in VEHSS.
* **Suppression burden:** 28.3% of BRFSS Prevalence
  kidney/vision rows and 26.0% of CDI diabetes/ESKD rows are suppressed,
  versus 9.7% for USDSS. This is mostly small strata.
* **Kidney:** no state-level CKD prevalence based on laboratory data is published on
  data.cdc.gov. The dedicated CKD Surveillance System site was unavailable during
  the build.

### 3. Pilot: states that rank high on several conditions (2022)

| Indicator | Source | Measure | Unit | Median | Lowest | Highest | Top-third states with CI above median |
|---|---|---|---|---|---|---|---|
| Self-reported chronic kidney disease | brfss_prevalence | crude_prevalence | % | 3.5 | AK 2.4 | WV 4.9 | 14 of 17 |
| Diagnosed diabetes among adults | usdss_state | crude_prevalence | % | 11.5 | DC 8.0 | WV 17.4 | 15 of 17 |
| Incidence of treated end-stage kidney disease | cdi | adjusted_rate | per 1,000,000 | 336.3 | VT 128.2 | OK 460.0 | no CI published |
| Blind or serious difficulty seeing | vehss_brfss | crude_prevalence | % | 5.2 | UT 3.5 | MS 10.5 | 16 of 17 |

State rankings move together. Spearman ρ between diagnosed diabetes and
self-reported kidney disease is 0.71, between diabetes and
vision difficulty 0.69, and between diabetes and treated ESKD
incidence 0.70.

**6 states are in the top third on all four indicators:
AR, KY, LA, OK, TN, WV.** By Census region, the 13 states in the top
third on three or more indicators are:
South 11, Midwest 2.

VEHSS also publishes the person-level picture. Among adults with diabetes, the
age-adjusted prevalence of blindness or serious difficulty seeing has a median of
**10.4%** across states, compared with **4.4%** among adults
without diabetes.

These are descriptive, ecological patterns. They do not show that the same
people have several conditions (except the VEHSS stratum) and do not imply
causation. See [limitations](limitations.md).

## Recommendations for harmonization

1. **Publish a shared minimal schema.** Make `indicator_id, measure_type, unit,
   geo_fips, year, strat_category, strat_value, estimate, ci_low, ci_high,
   suppressed_flag, data_source` the minimum every system exports. Put
   source-specific detail in extra columns. This model is a working example.
2. **Separate measure type from stratifiers.** Never encode "Crude" or
   "Age-Adjusted" inside an age column.
3. **Use standard codes.** FIPS for geography; a common code list for
   race/ethnicity, sex and age bands, with a shared 65+ band. Keep finer bands as
   optional extras.
4. **Machine-readable suppression.** Publish a boolean `suppressed` plus a reason
   code, not only footnote symbols that differ by system.
5. **Publish standard errors or sample sizes.** Only USDSS publishes SEs. Without
   them, users cannot test differences or pool estimates.
6. **Bounded intervals for proportions.** Logit or Wilson-type intervals avoid
   negative lower limits.
7. **Stable indicator ids across question revisions**, with a version field
   (for example `CKD_SELF_REPORT` v2019) instead of a new id.
8. **Document cross-system reconciliation.** When two systems publish the same
   BRFSS indicator, say which is authoritative and document any processing
   differences, so users do not have to infer them (as with 2020 here).
9. **Version and timestamp releases.** Socrata `rowsUpdatedAt` is the only version
   signal today. A release tag would make refreshes auditable.
10. **Fill the kidney gap.** A state-level CKD prevalence indicator based on
    laboratory data, published in the same layout, would make kidney disease as
    comparable as diabetes.
